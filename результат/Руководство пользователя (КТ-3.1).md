# Руководство пользователя (User Guide)

## 1. Определение документа
Руководство описывает порядок развертывания Faunistica_4.0 (для администратора) и сценарии работы в интерфейсе (для пользователя).

## 2. Назначение документа
- Обеспечить воспроизводимый запуск системы.
- Упростить обучение пользователей и снизить нагрузку на поддержку.

## 3. Часть 1: Руководство администратора

### 3.1. Системные требования
- ОС: Linux/macOS/Windows (x64).
- RAM: 4 ГБ+ (рекомендовано 8 ГБ).
- Диск: от 2 ГБ.
- Порты: 8000 (backend), 5432 (PostgreSQL), 8080 (pgAdmin опционально), 5173 (frontend dev).

**ПО:**
- Docker + Docker Compose.
- Python 3.11+.
- Node.js 20+.
- pnpm.
- uv (менеджер пакетов Python).
- Git.

### 3.2. Развертывание (Deploy)
1. Клонировать репозиторий:
   - `git clone <repo>`
2. Настроить backend:
   - Перейти в `backend/`.
   - Скопировать `.env.example` → `.env` и заполнить значения (см. ниже).
3. Запустить БД:
   - `docker compose up -d`
4. Установить зависимости и запустить backend:
   - `make run` (или `uv run fastapi dev src/app.py`)
5. Применить миграции:
   - `make migrate` (alembic upgrade head)
6. (Опционально) создать тестовые данные:
   - `./init.sh` (создаст тестового пользователя).
7. Настроить frontend:
   - Перейти в `frontend/`.
   - Скопировать `.env.example` → `.env`, указать `VITE_API_URL`.
   - `pnpm install`.
   - `pnpm dev`.

### 3.3. Переменные окружения (ключевые)
**Backend (.env):**
- `BOT_TOKEN`, `ADMIN_CHAT_ID` — Telegram бот и чат поддержки.
- `DB_NAME`, `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` — подключение к Postgres.
- `JWT_SECRET`, `ENCRYPT_SECRET` — секреты безопасности.
- `LOG_LEVEL` — уровень логирования.
- `PGADMIN_DEFAULT_EMAIL`, `PGADMIN_DEFAULT_PASSWORD` — если используется pgAdmin.

**Frontend (.env):**
- `VITE_API_URL` — адрес backend API.

### 3.4. Администрирование и поддержка
- Админ‑чат в Telegram получает обращения пользователей.
- Доступны команды:
  - `/reply` — ответить пользователю из админ‑чата (как ответ на его сообщение).
  - `/logs` — получить лог‑файлы за дату (формат YYYY‑MM‑DD или «сегодня»).
- PgAdmin (опционально) позволяет администратору управлять БД.

## 4. Часть 2: Руководство пользователя

### 4.1. Обзор интерфейса
- **Главная** — описание проекта и вход.
- **Инструкция** — пошаговая помощь по регистрации и заполнению форм.
- **Форма** — основная рабочая область для ввода данных о находке.
- **Профиль** — личная статистика, список записей, экспорт.
- **Статистика** — общая статистика по проекту.
- **Обратная связь** — отправка обращения в поддержку.

### 4.2. Типовые сценарии (How‑to)
**Сценарий 1: Регистрация и вход**
1. Открыть Telegram‑бота `@FaunisticaV3Bot` и выполнить `/register`.
2. Завершить регистрацию (имя, возраст, предпочтения).
3. Открыть сайт и войти по логину/паролю, полученным в боте.

**Сценарий 2: Заполнение новой записи**
1. Перейти в раздел «Форма».
2. Выбрать публикацию.
3. Заполнить блоки: административный, географический, сбор материала, таксономия.
4. Отправить запись на проверку.

**Сценарий 3: Редактирование записи**
1. Открыть «Профиль».
2. Выбрать запись из списка.
3. Внести изменения и сохранить.

**Сценарий 4: Экспорт данных**
1. В «Профиле» нажать «Скачать записи».
2. Получить файл `records.xlsx`.

**Сценарий 5: Обращение в поддержку**
1. Открыть «Обратная связь».
2. Указать Telegram‑ник и описание проблемы.
3. Отправить заявку — ответ придёт в Telegram.

### 4.3. FAQ
**Q: Не получается войти на сайт.**
A: Убедитесь, что регистрация в Telegram завершена и введены корректные логин/пароль.

**Q: Форма не отправляется.**
A: Проверьте обязательные поля и формат координат/дат.

**Q: Экспорт не запускается.**
A: Проверьте авторизацию и наличие записей в профиле.

**Q: Куда писать при проблемах?**
A: Используйте раздел «Обратная связь» на сайте или команду `/support` в боте.
